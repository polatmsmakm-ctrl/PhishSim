# PhishSim iOS + GitHub Actions

هذه الحزمة تحول المشروع إلى تطبيق iOS أصلي (SwiftUI) يعمل كواجهة تحكم لخادم PhishSim الموجود على جهاز كمبيوتر/خادم داخل شبكة محلية موثوقة.

## ما الذي يتضمنه؟
- تطبيق iOS عربي: تسجيل دخول، عرض الحملات والتقارير، إنشاء حملة كمسودة، تفعيل/إيقاف/إكمال الحملة، وتسجيل تفاعلات تدريبية يدوياً.
- API محلي في `backend/server.py` يستخدم قاعدة البيانات ومدير الحملات الأصليين.
- GitHub Actions يبني IPA غير موقّع، مناسب لإعادة التوقيع عبر Sideloadly.

## 1) تشغيل الخادم على الكمبيوتر

يتطلب Python 3.10+ ولا يحتاج مكتبات خارجية:

```bash
cd backend
python server.py
```

يبدأ الخادم على المنفذ `8765` ويستمع على واجهات الشبكة. اعرف عنوان IP المحلي للكمبيوتر (مثلاً `192.168.1.10`) واسمح بالمنفذ 8765 في جدار الحماية للشبكة الخاصة فقط.

**أمان:** لا تعمل Port Forwarding ولا تنشر هذا الخادم على الإنترنت. واجهة API الحالية HTTP للتجربة على شبكة خاصة موثوقة فقط؛ لا تستخدمها لنقل بيانات حساسة أو عبر Wi-Fi عام. للإنتاج يلزم HTTPS ومصادقة مركزية وإدارة جلسات أقوى.

## 2) إعداد حساب المشرف

أنشئ حساب المشرف مرة واحدة بتشغيل `python main.py` من مجلد `backend`، واتبع التعليمات في Terminal. بعد إنشاء الحساب أوقف واجهة CLI وشغّل `python server.py`. لا تستخدم كلمة مرور سبق استخدامها في خدمات أخرى.

## 3) إعداد التطبيق

افتح التطبيق بعد تثبيته، واكتب عنوان الخادم مثل:

`http://192.168.1.10:8765`

ثم سجّل الدخول بحساب المشرف.

## 4) بناء IPA عبر GitHub Actions

1. أنشئ مستودع GitHub جديداً وارفع محتويات هذا المجلد إلى الفرع `main`.
2. افتح تبويب **Actions**.
3. اختر **Build PhishSim IPA** ثم **Run workflow** (أو ادفع commit إلى `main`).
4. بعد نجاح البناء، افتح صفحة تشغيل الـ workflow ونزّل artifact باسم `PhishSim-IPA`.
5. فك ضغط artifact لتحصل على `PhishSim.ipa`.
6. افتح Sideloadly، اختر ملف IPA، وصل الآيفون، ثم اضغط Start وسجّل Apple ID عند الطلب.

الـ IPA الناتج غير موقّع من GitHub؛ Sideloadly يعيد توقيعه باستخدام حساب Apple الخاص بك. مدة صلاحية التثبيت تعتمد على نوع حساب Apple وطريقة التوقيع.

## حدود النسخة

هذه نسخة إدارة وتوعية فقط. لا ترسل رسائل بريد، ولا تنشئ صفحات انتحال، ولا تجمع كلمات مرور أو رموز جلسات. تسجيل النقرات والبلاغات تجريبي ويدوي. التطبيق يحتاج الخادم كي يعرض البيانات، ولا يخزن قاعدة البيانات داخل الآيفون.
